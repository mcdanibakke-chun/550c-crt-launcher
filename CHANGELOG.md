# Changelog

## 0.1.0-preview.1 — 2026-10-05

- First clean GitHub-ready public candidate, preserving the separate private project.
- Gray/white CRT Full boot and official appearance preset with Consolas / NSimSun fallback.
- Original gray terminal icon, eight Windows ICO sizes and embedded executable icons.
- External MSIX activation/window/reveal controller; actual registered target and process-name discovery, no installed-version paths in launch config.
- Standalone preview, configurable skip/wait/fade, interactive visual buttons/window controls and optional user-supplied local audio.
- Silent default; exclude unlicensed music, modified GPT-knot icons, system font files and private/reference material.
- Pinned, hash-verified WebView2 SDK restore; existing Framework build, isolated tests, public package checks and manual CI build.
- Preview status retained: real-device/cold-start/font-import acceptance remains pending.
