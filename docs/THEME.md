# 主题、字体与恢复

`themes/550C_GRAY_CRT_v02.txt`：背景 #080909、正文 #bfc1b6；Consolas 英文，新宋体与宋体中文回退。新增/移除/技能标记分别 #b3b775、#cf7880、#aeb0a7；原生 codex 代码高亮，对比度 60，非半透明窗口。

导入前通过官方主题“复制”保存自己的当前文本，再在官方设置 → 视觉风格 → 深色 → 主题导入中粘贴预设完整一行。应用是用户操作；此套件不会改用户设置文件。导入后再复制一次主题，确认字体字段并实看中英文。

此预设面向提供原生主题导入功能的客户端版本。若你的设置中没有该入口，主题导入部分不可用；独立动画仍可使用。不要为此修改客户端文件或注入样式。

恢复：导入自己保存的原主题，并恢复原来的系统/深色/浅色模式。没有通用的“用户原主题”文件随包发送，因为每个人的配置不同。

此字体列表仅引用已安装字体，未下载或携带字体文件。中文字体缺失时会回退；不同 Windows、DPI、字体渲染条件的观感不同。聊天主题不增加 CRT 扫描线或改变官方布局；扫描线、多栏终端和交互弹窗属于独立启动动画。
