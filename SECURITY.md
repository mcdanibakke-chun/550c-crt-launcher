# Security

This external launcher never modifies official client files, WindowsApps/Store packages, credentials, cookies, system security settings or startup registration. It does not inject, hook or attach a debugger. Original official launch entries remain independently usable.

Use only source/release packages from a maintainer you trust and compare SHA256 manifests. Releases are currently unsigned preview executables; the project does not disable SmartScreen/Defender or claim a Microsoft/OpenAI signature. Local configuration, audio and diagnostic logs are user-owned. Review text before sharing logs and do not publish credentials or unrelated screenshots.

For a vulnerability, use the repository's private vulnerability reporting if enabled by its owner. If that feature is not enabled, ask the owner to provide a private channel before sending sensitive evidence. No email or reporting account is invented by this template.
